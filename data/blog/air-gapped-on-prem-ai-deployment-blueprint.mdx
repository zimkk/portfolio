# The Air-Gapped AI Blueprint: Deploying Sovereign LLMs in Regulated Defense and Banking

If you propose calling an external cloud API in a Tier-1 investment bank or defense intelligence facility, your security review will end in approximately four seconds.

In these environments, data exfiltration is a felony. Network interfaces have strict firewall egress blocks, and the entire computing infrastructure operates in an **air-gapped private intranet**.

Yet these organizations desperately need modern document intelligence, automated code synthesis, and multi-agent operations.

Here is the exact hardware, orchestration, and inference architecture I use to deploy high-throughput, sovereign on-premise AI clusters that achieve parity with GPT-4o while remaining 100% disconnected from the public internet.

## The Physical Topology: Hardware and Cluster Architecture

An enterprise on-premise AI cluster does not require a $5 million supercomputer. A dedicated 4U rack server with 4x to 8x NVIDIA L40S (48GB) or H100 (80GB) GPUs handles 80% of enterprise workloads at sub-20ms Time-to-First-Token.

```
               │

```

## Step-by-Step Sovereign Deployment

### Step 1: Immutable Container Packaging

In an air-gapped environment, you cannot run `pip install` or pull models from HuggingFace at runtime. All weights, tokenizers, and dependencies must be pre-baked into a cryptographically signed container image:

```dockerfile:Dockerfile.sovereign
FROM vllm/vllm-openai:v0.6.3

# Copy pre-downloaded, verified model weights directly into the image
COPY ./model_weights/Qwen2.5-72B-Instruct-AWQ /opt/models/qwen72b
COPY ./model_weights/bge-m3 /opt/models/bge-m3

# Environment parameters for air-gapped execution
ENV HF_HUB_OFFLINE=1
ENV TRANSFORMERS_OFFLINE=1
ENV VLLM_GPU_MEMORY_UTILIZATION=0.92

EXPOSE 8000
ENTRYPOINT ["python3", "-m", "vllm.entrypoints.openai.api_server",             "--model", "/opt/models/qwen72b",             "--quantization", "awq",             "--tensor-parallel-size", "4",             "--port", "8000"]
```

### Step 2: High-Throughput Batch Serving with vLLM PagedAttention

By configuring PagedAttention and AWQ 4-bit quantization, a single node with 4x L40S GPUs achieves over **1,200 tokens per second** sustained throughput across 64 concurrent operator sessions:

```python:local_inference_gateway.py
import httpx
from pydantic import BaseModel
from typing import List, Dict, Any

class SovereignLLMGateway:
    def __init__(self, internal_vllm_url: str = "http://10.0.4.12:8000/v1"):
        self.client = httpx.AsyncClient(base_url=internal_vllm_url, timeout=30.0)

    async def generate_response(self, messages: List[Dict[str, str]], temperature: float = 0.1) -> str:
        # Calls local air-gapped OpenAI-compatible endpoint with zero external telemetry
        response = await self.client.post("/chat/completions", json={
            "model": "/opt/models/qwen72b",
            "messages": messages,
            "temperature": temperature,
            "max_tokens": 2048,
        })
        response.raise_for_status()
        return response.json()["choices"][0]["message"]["content"]
```

## Compliance Audit Checklist for Air-Gapped AI

1. **Verify offline flags**: `HF_HUB_OFFLINE=1` and `TRANSFORMERS_OFFLINE=1` prevent inadvertent DNS resolution attempts.
2. **Local embedding parity**: Run `bge-m3` or `nomic-embed-text` locally inside PostgreSQL with `pgvector` to keep retrieval 100% on NVMe disks.
3. **Log telemetry locally**: Ship audit logs to an internal SIEM (Splunk / Elasticsearch) with zero external pingbacks.
