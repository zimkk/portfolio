# Context Poisoning: Why Your AI Agent Gets Dumber the Longer You Chat with It (And How Vector Pruning Saves It)

Have you ever noticed that an AI agent feels razor-sharp during the first five turns of a conversation, but by turn 35 it starts repeating debunked hypotheses and mixing up deprecated variable names?

This is **Context Poisoning**.

In modern agentic architectures, every retrieved document chunk, intermediate tool observation, and diagnostic trial gets appended to a persistent memory store.

As conversations evolve, early assumptions are invalidated. Yet naive vector retrieval continues matching those outdated, contradictory chunks because they share high semantic similarity with your latest query.

## The Solution: Epistemic Vector Decay

```python:epistemic_memory.py
import math
import numpy as np

class EpistemicMemoryStore:
    def __init__(self, decay_lambda: float = 0.05):
        self.nodes = {}
        self.decay_lambda = decay_lambda

    def retrieve_clean_context(self, query_vector: np.ndarray, current_turn: int, top_k: int = 4):
        scored_nodes = []
        for node in self.nodes.values():
            if node.is_superseded:
                continue
            similarity = np.dot(query_vector, node.embedding) / (np.linalg.norm(query_vector) * np.linalg.norm(node.embedding))
            epistemic_weight = math.exp(-self.decay_lambda * (current_turn - node.turn_index))
            scored_nodes.append((similarity * epistemic_weight, node))

        scored_nodes.sort(key=lambda x: x[0], reverse=True)
        return [node.content for score, node in scored_nodes[:top_k] if score > 0.40]
```
