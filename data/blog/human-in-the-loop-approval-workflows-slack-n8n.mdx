# Building Bulletproof Human-in-the-Loop Approval Workflows with Slack and n8n

Full autonomy is a great marketing buzzword, but in real enterprise operations, you do not want an AI agent to automatically refund a $5,000 invoice or delete an AWS database without human sign-off.

The winning operational pattern is **Autonomous Draft + Human Approval**.

The AI does 98% of the tedious research, extracts the facts, drafts the response, and posts an interactive card to a private Slack channel with two buttons: `[Approve & Execute]` or `[Reject & Modify]`.

When an operator clicks the button on their mobile phone, the n8n workflow instantly wakes up, verifies the operator's identity, and executes the final action.

## The Interactive Wait Architecture

```
[AI Agent Drafts High-Stakes Action]
                │
                ▼
[n8n Generates Ephemeral Webhook Wait Node]
                │
                ▼
[Posts Interactive Block Kit Message to Slack #approvals]
 ├─ Shows AI Reasoning Summary
 ├─ Highlights Payout Amount ($4,500.00)
 └─ Buttons: [Approve] | [Reject]
                │
        (Operator Clicks Button in Slack)
                │
                ▼
[n8n Resumes Suspended Execution -> Dispatches Final API Action]
```

## Step 1: Generating Slack Block Kit UI in n8n

```json:slack_approval_card.json
{
  "blocks": [
    {
      "type": "section",
      "text": {
        "type": "mrkdwn",
        "text": "*AI Refund Proposal*: Customer *Acme Corp* requested $4,500 refund.
*Reasoning*: Contract SLA clause 8.2 breached due to 4h outage."
      }
    },
    {
      "type": "actions",
      "elements": [
        {
          "type": "button",
          "text": { "type": "plain_text", "text": "Approve Refund" },
          "style": "primary",
          "url": "{{ $node['Wait'].resumeUrl }}?action=approved&user={{ $json.userId }}"
        },
        {
          "type": "button",
          "text": { "type": "plain_text", "text": "Reject" },
          "style": "danger",
          "url": "{{ $node['Wait'].resumeUrl }}?action=rejected&user={{ $json.userId }}"
        }
      ]
    }
  ]
}
```
