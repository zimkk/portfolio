# Taming the Unstructured: Accurate Table and Chart Extraction from Scanned PDF Documents

If your enterprise RAG pipeline processes financial earnings reports, engineering schematics, or insurance loss runs, text-only OCR tools like Tesseract or PyPDF are completely useless.

A 5-column balance sheet with merged header rows gets flattened into a single stream of text. Column 2 numbers get interspersed with Column 4 descriptions.

When an analyst asks: *"What was Q3 European revenue in 2024?"*, the RAG system extracts a completely wrong number from an adjacent column.

Here is how to deploy a **Vision-First Multimodal Layout Pipeline** that indexes PDF pages as visual grids and preserves 100% tabular spatial alignment.

## The Vision-First Extraction Architecture

```
[Scanned PDF Document Page]
             │
             ▼
[Layout Analysis Model (Table Transformer / YOLOv10-Doc)]
 ├─ Detects Bounding Boxes for Tables, Charts, & Headers
 └─ Crops Table Regions into High-Res 300DPI Images
             │
             ▼
[Vision-Language Table Serializer (Qwen 2.5-VL / Claude Vision)]
 └─ Converts Image directly to Structured Markdown Table with Merged Headers
             │
             ▼
[Dual Vector Index: Markdown Table String + Crop Image Embedding]
```

## Code: Converting Visual Crops to Strict Markdown

```python:table_extractor.py
from PIL import Image
import httpx

async def serialize_table_crop_to_markdown(crop_image: Image.Image, vision_client) -> str:
    prompt = """
    Transcribe this financial table image into exact, valid GitHub-flavored Markdown table format.
    - Preserve all merged headers, currency symbols, and negative parenthetical values.
    - Output ONLY the clean Markdown table with zero conversational filler.
    """
    markdown_table = await vision_client.process_image(crop_image, prompt)
    return markdown_table
```

Treat tables as visual geometric structures, not flat strings of text.
