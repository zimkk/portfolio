# Beyond HTTP 500s: Building Observability for Semantic Drift in Production AI

For thirty years, software observability was built on clean binary signals:
- Did the server return HTTP 200 or HTTP 500?
- Is CPU utilization above 85%?
- Is P99 database latency under 50ms?

In the AI era, these traditional metrics are dangerously insufficient.

An LLM can return HTTP 200 in 350ms with 0% CPU strain while generating a response that hallucinates a nonexistent product feature or quotes the wrong regulatory fee.

Your Datadog dashboard is glowing green while your product is actively failing your customers.

Here is how to build an **OpenTelemetry-native Semantic Observability Stack** that monitors token entropy, semantic drift, and assertion invariants in real time.

## The Three Pillars of Semantic AI Observability

## The Production Implementation

Here is an OpenTelemetry custom span processor in Python that calculates semantic drift on every live response:

```python:semantic_tracer.py
from opentelemetry import trace
import numpy as np

tracer = trace.get_tracer("applied_ai.semantic_monitor")

class SemanticObservabilityMonitor:
    def __init__(self, reference_corpus_centroid: np.ndarray, threshold: float = 0.35):
        self.centroid = reference_corpus_centroid
        self.threshold = threshold

    def trace_generation(self, prompt: str, output: str, output_embedding: np.ndarray, entropy_score: float):
        with tracer.start_as_current_span("llm_semantic_evaluation") as span:
            # Calculate distance from healthy domain centroid
            distance = 1.0 - (np.dot(output_embedding, self.centroid) / (
                np.linalg.norm(output_embedding) * np.linalg.norm(self.centroid)
            ))

            span.set_attribute("ai.entropy_score", entropy_score)
            span.set_attribute("ai.drift_distance", float(distance))
            span.set_attribute("ai.output_length", len(output))

            if distance > self.threshold or entropy_score > 4.2:
                span.set_attribute("ai.semantic_anomaly", True)
                span.set_status(trace.StatusCode.ERROR, "High semantic drift detected")
                print(f"[ALERT] Semantic drift detected! Distance: {distance:.3f}")
```
