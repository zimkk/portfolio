# The Shadow AI Crisis: Regaining Control Over Unsanctioned Prompts in Enterprise Ops

Here is an uncomfortable truth every Fortune 500 CISO knows: **Your company is already running on AI.**

You have not approved it. Your legal department has not signed off on it. But your frontline underwriters, developers, customer service agents, and sales reps are pasting proprietary customer emails, financial spreadsheets, and source code into consumer AI chatbots every single day.

Why? Because consumer tools work in 2 seconds, while your official IT request ticket has been sitting in a security backlog for 14 weeks.

Outright banning AI does not work. Employees will just switch to their personal 5G mobile hotspots.

The only sustainable solution is to provide an **Enterprise AI Gateway Proxy** that makes the sanctioned internal tool faster and easier to use than consumer chatbots, while transparently tokenizing and redacting PII before any prompt leaves the corporate perimeter.

## The Reverse Proxy Architecture with Dynamic PII Masking

```
[Employee Workplace UI / API Client]
                 │
      (Raw Prompt with Sensitive PII)
                 │
                 ▼
[Enterprise AI Gateway (FastAPI / Rust)]
 ├─ Step 1: Presidio / Regex PII Detector
 ├─ Step 2: Vault Tokenizer (Replaces "John Doe" with "[CUSTOMER_TOKEN_41]")
 └─ Step 3: Rate Limiting & Enterprise Audit Logging
                 │
      (Sanitized Anonymized Payload)
                 │
                 ▼
[Frontier Model Provider (Claude / OpenAI Zero-Retention)]
                 │
      (Anonymized Response)
                 │
                 ▼
[Detokenization Layer: Re-injects "John Doe"] ──► [Delivered to Employee]
```

## The Production Implementation

Here is an enterprise-grade PII tokenization proxy in Python using Microsoft Presidio and Redis:

```python:pii_gateway_proxy.py
from presidio_analyzer import AnalyzerEngine
from presidio_anonymizer import AnonymizerEngine
import redis
import uuid
import json

class EnterprisePIIProxy:
    def __init__(self, redis_host: str = "localhost"):
        self.analyzer = AnalyzerEngine()
        self.anonymizer = AnonymizerEngine()
        self.vault = redis.Redis(host=redis_host, port=6379, db=0)

    def mask_and_vault_prompt(self, raw_prompt: str, session_id: str) -> str:
        # Detect names, SSNs, credit cards, and email addresses
        results = self.analyzer.analyze(text=raw_prompt, language="en")
        
        token_map = {}
        anonymized_text = raw_prompt
        
        # Sort entities in reverse order to preserve string slicing offsets
        for entity in sorted(results, key=lambda x: x.start, reverse=True):
            original_value = raw_prompt[entity.start:entity.end]
            token_id = f"[{entity.entity_type}_{uuid.uuid4().hex[:6]}]"
            
            token_map[token_id] = original_value
            anonymized_text = anonymized_text[:entity.start] + token_id + anonymized_text[entity.end:]

        # Store detokenization mapping in ephemeral Redis cache (5-minute TTL)
        self.vault.setex(f"pii_session:{session_id}", 300, json.dumps(token_map))
        return anonymized_text

    def unmask_response(self, model_response: str, session_id: str) -> str:
        cached_map = self.vault.get(f"pii_session:{session_id}")
        if not cached_map:
            return model_response

        token_map = json.loads(cached_map.decode("utf-8"))
        detokenized_text = model_response
        for token_id, original_value in token_map.items():
            detokenized_text = detokenized_text.replace(token_id, original_value)

        return detokenized_text
```

## Benefits for Enterprise Risk Management

- **Zero PII Exfiltration**: Frontier models only see abstract tokens like `[PERSON_a4b1]` and `[EMAIL_c92f]`.
- **Zero Employee Friction**: The employee gets the exact answers they need with full real names restored transparently.
- **Complete Audit Trail**: Security teams can query who prompted what without storing unmasked data in cloud provider logs.
